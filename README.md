# 月迹（Lunartrace）

离线、零网络的月经与症状记录 Android 应用。记录由你手动输入，推算只在本机完成。

## 这是什么工程

除了一个 Android 应用，本仓库还包含一套**约束工程**：让"单人 + AI"协作时不靠记忆、靠可执行门禁来保证质量。

## 三条不可违反的原则

1. **零网络**：清单不含任何联网权限；没有账号、没有同步、没有埋点。
2. **数据主权**：一键清除即真删除；PIN 忘记只能清除，不留后门。
3. **不假装**：没测的说没测，没做的说没做，文档不许比代码新。

快速开始见 `DEVELOP.md`。
